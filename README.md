# Vleer Docs

Documentation for [Vleer](https://vleer.app), live at [docs.vleer.app](https://docs.vleer.app).

- Install, configure and understand the Vleer app
- Vleer API (`api.vleer.app`): downloads, updates and telemetry
- OpenMusicMetadata API: canonical songs, albums and artists

Built with Next.js and Fumadocs.

```sh
bun install
bun dev
```

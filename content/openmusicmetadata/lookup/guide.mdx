---
title: Lookup
description: Fetch resources by id, ISRC, or UPC.
icon: pixelarticons:book-open
---

Use lookup when you already have OpenMusicMetadata ids, a song ISRC, or an album UPC.

`ids`, `isrc`, and `upc` are separate lookup modes and cannot be combined in the same request.

## One Resource

```http
GET /lookup/omm:song:1
```

The response is `Single<Song | Album | Artist>`.

## Many Resources

```http
GET /lookup?ids=omm:song:1,omm:album:2,omm:artist:3
```

The response is a `Collection<Song | Album | Artist>`. Returned resources keep the request order. Missing ids are omitted from `data`.

Lookup requests with `ids` support at most 100 ids.

## By ISRC

```http
GET /lookup?isrc=USRC17607839
```

The response is a `Collection<Song>`.

## By UPC

```http
GET /lookup?upc=602455878540
```

The response is a `Collection<Album>`.

## Includes

Songs can include albums and artists:

```http
GET /lookup/omm:song:1?include=albums,artists
```

Albums can include artists:

```http
GET /lookup/omm:album:2?include=artists
```

Artists do not support includes.

## Fields

Use scoped fields to keep responses small.

```http
GET /lookup/omm:song:1?fields[song]=name,isrc&fields[artist]=name
```

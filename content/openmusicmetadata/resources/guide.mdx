All resources share the same core shape.

```ts
type Type = "song" | "album" | "artist";

interface Resource {
  id: `omm:${Type}:${string}`;
  type: Type;
}
```

## Relationships

Only these relationships exist, and they are always returned:

| Resource | Relationships       |
| -------- | ------------------- |
| `song`   | `albums`, `artists` |
| `album`  | `artists`           |

## Value formats

- `releaseDate` is `YYYY`, `YYYY-MM` or `YYYY-MM-DD`.
- `genres` is omitted when empty, never an empty array.
- `artworkUrl` may contain `{w}` and `{h}` placeholders, see [API Specifications](/openmusicmetadata/implementation#artwork).
- `artistNames` is ordered by name.

`/lookup/{id}` returns one resource in `data`.

```ts
interface Single<T extends Resource> {
  data: T;
}
```

Lists use `data` and `meta`. Lookup collections use `data`.

```ts
interface List<T extends Resource> {
  data: T[];
  meta: {
    total?: number;
  };
}

interface Collection<T extends Resource> {
  data: T[];
}
```

`GET /` returns the raw `Metadata` object without a `data` wrapper.

`/lookup?ids=...` returns a collection because it can contain mixed resource types. `/lookup?isrc=...` returns a song collection. `/lookup?upc=...` returns an album collection.

`/match/song` returns one song in `data`.

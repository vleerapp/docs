title: Catalog
description: Fetch resources by id, ISRC, or UPC.

Use the catalog when you already have OpenMusicMetadata ids, a song ISRC, or an album UPC. Every resource is returned with all of its attributes and relationships.

`ids`, `isrc`, and `upc` are separate modes and cannot be combined in the same request. Providing none or more than one returns `400`.

Requests support at most 100 comma-separated values and 10000 characters.

| Mode   | Order                                                                          |
| ------ | ------------------------------------------------------------------------------ |
| `ids`  | Request order. Duplicate ids are returned once per occurrence                  |
| `isrc` | Ordered by id                                                                  |
| `upc`  | Ordered by id                                                                  |

Invalid ids, unknown values and missing resources are omitted from `data`. Songs without an artist or album, and albums without an artist, are treated as missing.

## One Resource

```http
GET /catalog/omm:song:0a1b2c3d4e5f6g7h
```

The response is `Single<Song | Album | Artist>`. Returns `404` if the resource doesn't exist.

## Many by Id

```http
GET /catalog?ids=omm:song:0a1b2c3d4e5f6g7h,omm:album:1a2b3c4d5e6f7g8h,omm:artist:2a3b4c5d6e7f8g9h
```

The response is `List<Song | Album | Artist>`.

## Many by ISRC

ISRC values are matched case-insensitively.

```http
GET /catalog?isrc=USRC17607839
```

The response is `List<Song>`.

## Many by UPC

```http
GET /catalog?upc=602455878540
```

The response is `List<Album>`.

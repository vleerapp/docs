Errors are returned as JSON.

```ts
interface ErrorResponse {
  error: {
    status: number;
    message: string;
  };
}
```

```json
{
  "error": {
    "status": 400,
    "message": "Provide exactly one of ids, isrc, or upc"
  }
}
```

## Status codes

| Status | Meaning                                                                     |
| ------ | --------------------------------------------------------------------------- |
| `400`  | Invalid request, for example a malformed id, a missing `name` or too many lookup values |
| `404`  | The resource wasn't found, or `identify` found no match                     |
| `429`  | Rate limit exceeded                                                         |
| `500`  | Unexpected server error                                                     |
| `503`  | The metadata database is temporarily unavailable                            |
| `504`  | The query timed out                                                         |

## Rate limits

Rate limited requests return `429` with a plain text body, a `retry-after` header and an `x-ratelimit-after` header. Both headers contain the number of seconds to wait.

```txt
Too Many Requests! Wait for 1s
```

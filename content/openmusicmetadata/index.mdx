OpenMusicMetadata is a read-only metadata API for canonical songs, albums, and artists. OpenMusic servers can use OpenMusicMetadata ids to map the same musical entity across different catalogs.

## Resource Types

- `song`
- `album`
- `artist`

## Main Workflows

Use `/catalog` when you already have OpenMusicMetadata ids, a song ISRC, or an album UPC.

```http
GET /catalog/omm:song:0a1b2c3d4e5f6g7h
GET /catalog?ids=omm:song:0a1b2c3d4e5f6g7h,omm:album:1a2b3c4d5e6f7g8h
GET /catalog?isrc=USRC17607839
GET /catalog?upc=602455878540
```

Use `/identify/{type}` when you need to identify the canonical OpenMusicMetadata resource for metadata.

```http
GET /identify/song?name=blue&artist=example
GET /identify/album?name=blue&artist=example
GET /identify/artist?name=example
```

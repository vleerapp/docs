## Base URL

```txt
https://api.vleer.app/metadata/v1
```

## Resource ids

Resource ids are OpenMusicMetadata ids in the form `omm:TYPE:ID`, where `ID` is a positive integer without leading zeros, currently 10 digits and at most 18. Treat it as an opaque string: do not parse it, and compare ids as text.

```txt
omm:song:1482910533
omm:album:1193847211
omm:artist:1005712044
```

Each resource has an `id`, a singular `type`, `attributes`, and for songs and albums `relationships`.

## Relationships

Every response contains all available attributes and relationships. There is nothing to opt into.

| Resource | Relationships       |
| -------- | ------------------- |
| `song`   | `albums`, `artists` |
| `album`  | `artists`           |

Relationships are one level deep. Albums nested in a song's `relationships` don't have relationships of their own.

## Artwork

`artworkUrl` may contain `{w}` and `{h}` placeholders. Replace them with the width and height in pixels you want.

```txt
https://example.com/image/{w}x{h}.jpg
```

## Rate limits

Requests are rate limited per client IP with a burst of 20 requests, refilling one request every 50 ms. Exceeding the limit returns `429`, see [Error Response](/openmusicmetadata/error-response).

## CORS

Browser requests are only allowed from an allowlist of origins. Call the API from a server or native app.

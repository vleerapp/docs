Resource ids are OpenMusicMetadata ids in the form `omm:TYPE:ID`, where `ID` is 16 lowercase alphanumeric characters.

```txt
omm:song:0a1b2c3d4e5f6g7h
omm:album:1a2b3c4d5e6f7g8h
omm:artist:2a3b4c5d6e7f8g9h
```

Each resource has an `id`, a singular `type`, `attributes`, and optional `relationships`.

## Includes

OpenMusicMetadata supports only these includes:

| Resource | Includes |
| --- | --- |
| `song` | `albums`, `artists` |
| `album` | `artists` |

Includes are limited to one relationship level.

Included relationships are returned completely for the metadata record.

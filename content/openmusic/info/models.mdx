## Info

```ts
interface Info {
  branding: {
    name: string;
    description?: string;
    logoUrl?: string;
    shortName?: string;
    themeHex?: string;
    website?: string;
    email?: string;
    location?: string;
    operator?: string;
  };
  openmusic: {
    version: "1.0";
    capabilities: ("streaming" | "stations" | "explore")[];
  };
  authentication?: {
    methods?: AuthenticationMethod[];
  };
}
```

`location` is an ISO 3166-1 alpha-2 country code.

See [Authentication](/openmusic/info/authentication) for the authentication method model and usage.

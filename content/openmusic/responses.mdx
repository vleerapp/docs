Single resources use a response object with `data`.

```ts
interface Single<T extends Resource> {
  data: T;
}
```

Example:

```json
{
  "data": {
    "id": "artist_123",
    "type": "artist",
    "attributes": {
      "name": "Example Artist"
    }
  }
}
```

Lists and collections use `data` and `meta`.

## List

```ts
interface List<T extends Resource> {
  data: T[];
  meta: {
    limit: number;
    offset: number;
    total?: number;
  };
}
```

Use lists for normal list endpoints and relationship endpoints.

The usual maximum `limit` is 100.

## Collection

```ts
interface Collection<T extends Resource> {
  data: T[];
  meta: {
    missingIds: Id[];
  };
}
```

Collections are used by lookup endpoints. Returned resources keep the request order. Missing ids are omitted from `data` and reported in `meta.missingIds`.

## Raw Objects

`GET /`, `GET /search`, `GET /search/suggestions`, and `GET /explore` return their model directly, without a `data` wrapper.

Errors always use the shared error envelope:

```ts
interface ErrorResponse {
  error: {
    status: number;
    message: string;
    details?: ErrorDetail[];
    requestId?: string;
  };
}
```

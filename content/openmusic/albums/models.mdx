## Album

```ts
interface Album extends Resource {
  type: "album";
  attributes: {
    name: string;
    trackCount: number;
    artistName?: string;
    artworkUrl?: string;
    upc?: string;
    genres?: string[];
    releaseDate?: string;
  };
  relationships?: {
    tracks?: List<Song>;
    artists?: List<Artist>;
  };
}
```

`releaseDate` may be `YYYY`, `YYYY-MM`, or `YYYY-MM-DD`.

`artistName` is a display fallback. Use `relationships.artists` when the client needs structured artist data.

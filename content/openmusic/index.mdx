OpenMusic is a read-only music API spec for exposing songs and related metadata
through a consistent resource model.

We maintain **openmusic-fs** as the reference implementation for a
local filesystem adapter in Go.

<GithubInfo owner="vleerapp" repo="openmusic-fs" />

It is the implementation used to validate and evolve the spec.

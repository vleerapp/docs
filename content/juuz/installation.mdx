juuz ships as a Docker image at `ghcr.io/vleerapp/juuz`. Stable releases are tagged `latest` and with their version, for example `0.1.0`. Nightly builds are tagged `nightly`. Save this as `docker-compose.yml`, point `/music` at your music folder and run `docker compose up -d`.

```yaml
services:
  juuz:
    image: ghcr.io/vleerapp/juuz:latest
    restart: unless-stopped
    ports:
      - "4533:4533"
    environment:
      JUUZ_ADMIN_PASSWORD: change-me
      JUUZ_OMM: "true"
      JUUZ_LASTFM_API_KEY: ""
      JUUZ_LASTFM_SECRET: ""
    volumes:
      - data:/data
      - /path/to/your/music:/music

volumes:
  data:
```

The server listens on port `4533`. See [Configuration](/juuz/config) for the environment variables.

<Callout title="Permissions" type="warn">
  The container runs as uid `1000`. The music folder must be writable by that user, since [uploads](/juuz/upload) are saved there. `/data` holds the database and caches.
</Callout>

## First login

Open `http://<host>:4533` and sign in as `admin`. The password is `JUUZ_ADMIN_PASSWORD`. If you leave it unset, juuz generates a random password and logs it once, so read it from `docker compose logs juuz` on the first start.

## Connecting a client

Point any OpenSubsonic client at `http://<host>:4533` with your juuz username and password, or with an [API key](/juuz/authentication#api-keys). Feishin and Arpeggi are tested.

## Updating

```sh
docker compose pull
docker compose up -d
```

The library database lives in the `/data` volume and is migrated automatically.
